### MVPの目的

Akariというサービスを作るうえで、核となるシステムの一つに見守りシステムがある。本MVPは、その見守りシステムが実現可能かを確かめるための検証である。

### 見守りシステムとは

既定時間以内に依頼人のデバイスから信号がサーバに送られたかを確認することで、依頼人の生存確認を行う仕組みである。

### 今回のゴール

ローカル環境でサーバ、クライアント、管理UIを連携させ、正しく動作させることで、自分のイメージを実際に形にできるかを検証することをゴールとした。

### 結果

クライアント、サーバ、管理UIをそれぞれ連携させ、見守りシステムの基礎部分を実装することができた。

### 現状の仕様・制約

- 本MVPはローカル環境でのみ動作確認を行っている。
- クライアント、サーバ、管理UIの3つで構成されている。
- クライアントからサーバへ定期的に生存信号を送信する。
- サーバは受信したクライアント情報をメモリ上で管理する。
- 管理UIはサーバからクライアントの状態を取得し、表示する。
- サーバを再起動すると、保持しているクライアント情報は失われる。
- 現在のクライアントは専用デバイスではなく、Pythonプログラムとして動作する。
- 本MVPではデータの永続保存、認証・認可などの本番環境向けの機能は実装していない。
- 見守りシステムはAkari全体のシステムの一部であり、依頼人のデータ管理や異常検知後の対応フローなどは今後検討する。

### Setup

#### Clone

```bash
git clone <repository-url>
cd akari-monitor
```
#### 必要環境
- Python
- Node.js
- Rust
- Tauri
- npm

#### 1. Server

Python仮想環境を有効化し、サーバを起動する。

```bash
cd server
source venv/bin/activate
python ...
```

#### 2. Client

別のターミナルでクライアントを起動する。

```bash
cd clients
source venv/bin/activate
python ...
```

#### 3. Dashboard

別のターミナルで管理UIを起動する。

```bash
cd dashboard/akari-monitor
npm install
npm run tauri dev
```

### Note

現在はLinux環境（WSL2 / Arch Linux）でのみ動作確認しています。
